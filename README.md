# Força Mística em Python

Primeiros experimentos com Python, unindo magia, números e lógica.

## Scripts incluídos

### 1. `ritualdasorte.py`
Um ritual matemático onde dois números aleatórios se encontram e somam suas forças.

**Exemplo de saída:**
```
NÚMEROS ESCOLHIDOS: 815  
NÚMEROS ESCOLHIDOS: 615  
MINHA FORÇA TOTAL: 1430
```

### 2. `quadradomagico.py`
Um quadrado mágico que revela o nível de força, sua raiz quadrada (aumentando o poder) e a raiz cúbica (diminuindo para revelar o oculto).

**Exemplo de saída:**
```
NÍVEL DE FORÇA: 100  
FORÇA AUMENTADA EM: 10.00%  
FORÇA DIMINUÍDA EM: 4.64%
```

## Tecnologias usadas
- Python 3.12  
- Módulos: `random`, `math`  
- IDE: PyCharm

## Objetivo
Treinar lógica, comandos básicos e formatar saídas de forma criativa. Sem estruturas ainda — só a base firme.
